# aska-yolculuk panel (retired)

This repository no longer hosts the customer panel snapshot. The encrypted payload files
(`index.html`, `panel-data.json`) were removed on 2026-10-02 as part of privacy hardening:
customer data is now served only by the authenticated server endpoint at
https://www.aska-yolculuk.com/musteri-paneli .

This repository is kept for the `panel.aska-yolculuk.com` CNAME record and may later host a
neutral notice page. No customer data, ciphertext or credentials are stored here.
