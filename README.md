# aska-yolculuk panel (ciphertext only)

This repository publishes the ADEN PLUS customer panel on `panel.aska-yolculuk.com`.

`index.html` contains only AES-256-GCM ciphertext (key derived with PBKDF2-SHA256, 210,000
iterations). The plaintext customer data never leaves the local CRM database; the page decrypts in
the browser after the correct password is entered. No customer name, phone number or message text
is present in this repository.

Generated by `scripts/tools/agentops/agent_crm_panel.js` in the private ADEN PLUS repository and
refreshed by the CRM sync job.
